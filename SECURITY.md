# Security Policy

## Supported versions

Only the latest code on `main` is supported. There are no maintained release
branches.

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or
discussions.

Report them privately through GitHub instead:

1. Open the [Security tab](https://github.com/KaanMyumyun/HospitalSystem/security)
   of this repository.
2. Choose **Report a vulnerability**.

Only the maintainer can see the report. Please include:

- what the problem is and which part of the system it affects
- steps to reproduce it
- the impact you expect

This is a personal project with a single maintainer, so responses are best
effort.

## Testing against the live demo

Please do not run automated scanners, load tests or brute-force attempts
against the live demo at hospitalsystem.pages.dev or its API. Run the project
locally instead; see [Getting Started](README.md#getting-started).
